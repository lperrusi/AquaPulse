# GitHub Pages (AquaPulse)

This folder is used for **GitHub Pages** so the privacy policy is available at a public URL for the App Store and Google Play.

**Repo:** https://github.com/lperrusi/AquaPulse

## Enable GitHub Pages

1. On GitHub: open the repo → **Settings** → **Pages** (left sidebar).
2. Under **Source**, choose **Deploy from a branch**.
3. Under **Branch**, select `main` (or your default branch) and folder **/docs**.
4. Click **Save**. After a minute or two, the site will be live at:
   - **Privacy policy:** https://lperrusi.github.io/AquaPulse/privacy-policy.html
